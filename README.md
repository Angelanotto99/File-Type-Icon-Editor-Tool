## 🧰 Troubleshooting Tips

### My icon didn't change. What should I do?

1. **Restart File Explorer** (right-click the taskbar, choose "Task Manager," find "Windows Explorer," and restart it)
2. **Reboot your computer** – this often refreshes the icon cache
3. **Try again** – sometimes the first click takes a moment to register

### Three icon hasn't changed after restart

Your computer stores icons in a cache. To refresh it:

1. Open the tool
2. Find the **"Refresh Icons"** button (usually under Settings or Tools)
3. Click it and restart your computer

### The tool won't open

- Make sure you have **administrator privileges** (right-click the tool and select "Run as Administrator")
- Check that your Windows is **up to date** (Settings → Update & Security → Windows Update)
- Temporarily disable **antivirus software** – then re-enable after installation
